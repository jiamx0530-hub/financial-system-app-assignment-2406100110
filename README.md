## 项目简介

“校园活动报名助手”使用 Java 和 XML 开发，包含两个 Activity，并通过 Intent 完成页面跳转和数据传递。项目使用了 TextView、EditText、Button、ImageButton、Spinner、RadioGroup、CheckBox 和 ListView 等控件。

## 运行说明

解压压缩包后，使用 Android Studio 打开源码工程，等待 Gradle 同步完成，选择安卓模拟器并运行即可。
